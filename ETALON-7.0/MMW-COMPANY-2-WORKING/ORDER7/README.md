# ORDER7

Отдельный коммерческий контур MMW-COMPANY/2.

Принцип изоляции:
- не изменяет публичные страницы MMW-COMPANY;
- использует отдельный Render Web Service;
- использует отдельную PostgreSQL базу;
- работает в той же репозитории и той же ветке, без создания нового workspace/ветки.

Текущий API:
- GET /health
- GET /api/catalog
- POST /api/orders
- GET /api/orders/lookup?code=12345
